# ⚽ FPL Mini-League War Room

A custom-built Fantasy Premier League dashboard to manage mini-leagues, spy on opponents, and gain a strategic edge.

## Features

- **Commissioner Tools:** Dual leaderboards, automatic Gameweek winner highlighting, and auto-generated WhatsApp summaries.
- **Spy Mode:** Compares opponents' squads, captains, and differentials directly against your team.
- **Strategy Lab:**
  - Bandwagon Tracker (Group ownership)
  - Expected Points (xPts) analysis
  - Fixture Difficulty Rating (FDR) calculations

## Tech Stack

- Python
- Streamlit
- Official FPL API
